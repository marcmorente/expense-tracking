# AGENTS.md

## Commit style

- Write all commits in lower case
- Start with a present-tense imperative verb: `add`, `fix`, `remove`, `refactor`, `update`, `rename`
- Keep to one logical change per commit
- Use a single-line subject only (no body)
- Use bare description for a single focus: `add openspec skills`
- Use parenthetical details for grouped items: `add php tooling (cs fixer, phpstan, deptrac)`
